# THYQERON CORE 1.0

Painel pessoal em formato PWA, adaptável ao Galaxy A12.

## Recursos
- Relógio e data em tempo real
- Temas escuro e claro
- Bloco de notas salvo no armazenamento local
- Temporizador de foco de 25 minutos
- Atalhos para sites e criação de links temporários
- Informações básicas de navegador, conexão e instalação
- Cache offline quando hospedado por HTTPS

## Publicar gratuitamente
1. Extraia o ZIP.
2. Entre em https://app.netlify.com/ e crie uma conta.
3. Use o deploy manual e envie o conteúdo desta pasta.
4. Abra o endereço HTTPS gerado no navegador do celular.
5. No menu do Chrome/Samsung Internet, escolha "Adicionar à tela inicial" ou "Instalar aplicativo".

## Limitações
Esta versão é um PWA, não um APK nativo e não contém uma IA conectada. Não consegue controlar todo o Android, ler livremente RAM/armazenamento/bateria ou ouvir a palavra de ativação com o app fechado. Notas são locais ao navegador; links personalizados existem apenas durante a sessão. Para conectar uma IA online, será necessário um serviço de IA e configuração segura de API.
